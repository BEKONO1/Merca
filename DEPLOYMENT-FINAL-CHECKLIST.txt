════════════════════════════════════════════════════════════════════════════
                          TROUBLESHOOTING QUICK GUIDE
════════════════════════════════════════════════════════════════════════════

ISSUE: docker-compose build fails
  └─ Check: docker version (need 20.10+)
  └─ Check: Dockerfile syntax (is it valid Docker?)
  └─ Run: docker-compose build --no-cache

ISSUE: docker-compose up fails
  └─ Check: Port 80 not in use (or use different port)
  └─ Check: Docker daemon running
  └─ Run: docker-compose up --build

ISSUE: Application not responding at http://localhost
  └─ Wait 15 seconds for Apache to fully start
  └─ Check: docker-compose logs app
  └─ Try: docker-compose exec app curl http://localhost/

ISSUE: Database connection error
  └─ Check: MySQL container started (docker-compose logs db)
  └─ Check: .env DATABASE_URL correct
  └─ Try: docker-compose exec db mysql -u root -p (then test)

ISSUE: Railway deployment fails
  └─ Check: railroad.toml syntax (valid TOML?)
  └─ Check: docker-compose.yml syntax
  └─ Check: GitHub sync (is code actually pushed?)
  └─ Check: Railway logs for specific error message

ISSUE: "Volumes not mounting correctly"
  └─ Verify: docker-compose.yml has .:/var/www/html
  └─ Check: Dockerfile WORKDIR is /var/www/html
  └─ Resync: docker-compose down && docker-compose up
