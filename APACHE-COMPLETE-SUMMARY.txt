KEY CHANGES EXPLAINED
═══════════════════════════════════════════════════════════════════════════

WHY APACHE NOW?

  php -S (old):
  ├─ Single-threaded (1 request at a time)
  ├─ NO .htaccess support
  ├─ NO mod_rewrite support
  ├─ ~100-200 RPS (requests/second)
  └─ NOT production-ready

  Apache (new):
  ├─ Multi-process (thousands concurrent)
  ├─ FULL .htaccess support
  ├─ mod_rewrite fully functional
  ├─ ~1500-3000+ RPS (10x faster! 🚀)
  └─ PRODUCTION-READY

WHY DOCUMENTARY ROOT IN /public?

  Security:
  ├─ application/ → PRIVATE (not web-accessible)
  ├─ system/     → PRIVATE (not web-accessible)
  ├─ src/        → PRIVATE (not web-accessible)
  ├─ public/     → PUBLIC (only this is accessible)
  └─ Sensitive files protected automatically

  Organization:
  ├─ Web assets (CSS, JS, images) → public/
  ├─ Application logic → application/
  ├─ Framework code → system/
  ├─ Configuration → application/config/
  └─ Clear separation of concerns
