                         ❌ PROBLÈMES CRITIQUES
══════════════════════════════════════════════════════════════════════════

🔴 PROBLÈME #1: docker-compose.yml INCOMPATIBLE

Situation actuelle:
  Dockerfile config:     php:8.3-apache (Apache built-in)
  docker-compose config: command: "php -S 0.0.0.0:8000" (built-in server)
  
  ⚠️  CONFLIT!
  
  Le Dockerfile est conçu pour Apache (démarre automatiquement)
  Mais docker-compose force le serveur built-in PHP
  → L'image Docker n'est pas utilisée correctement

Impacte:
  • docker-compose up = ne teste PAS l'image finale
  • Comportement différent local vs production
  • Apache configuration ignorée localement


🔴 PROBLÈME #2: CHEMINS INCOHÉRENTS

Dockerfile:        WORKDIR /var/www/html
docker-compose:    volumes: .:/app

  ⚠️  MISMATCH!
  
  Le Dockerfile copie dans /var/www/html
  docker-compose monte dans /app
  → Chemins incorrects, volumes non utilisés correctement


🔴 PROBLÈME #3: MANQUE FORMAT RAILWAY MODERNE

Situation actuelle:  railway.json (format Dockerfile builder)
Standard du modèle:  railway.toml (format docker-compose unified)

Problème:
  Le modèle Laravel 12 partagé utilise railroad.toml avec:
  
    [build]
    dockerComposeFile = "docker-compose.yml"
    dockerComposeService = "app"
  
  ✓ Approche unifiée (une source unique de config)
  ✓ Environnement local = production
  ✓ Plus facile à maintenir


🔴 PROBLÈME #4: composer.json MANQUE ext-intl

Config actuelle:
  require: {
    "ext-curl", "ext-pdo", "ext-pdo_mysql",
    "ext-mbstring", "ext-gd", "ext-json",
    "ext-openssl", "ext-zip"
  }
  
  ⚠️  MANQUE ext-intl!
  
  Dockerfile installe intl (line 29):
    docker-php-ext-install ... intl ...
  
  Mais composer.json ne le déclare pas
  → Incompatibilité possible, validation échouera


🔴 PROBLÈME #5: PHP 8.2 vs 8.3/8.4

composer.json:    "php": "^8.2"
Dockerfile:       php:8.3-apache
Railway standard:  php:8.4 (du modèle)

Impact:
  • Version déclarée vs version réelle = incohérence
  • Devrait spécifier ^8.3 minimum

CORRECTION #2: Mettre à jour docker-compose.yml

  app:
    build:
      context: .
      dockerfile: Dockerfile
    ports:
      - "${APP_PORT:-8000}:80"          # Port correct
    volumes:
      - .:/var/www/html                 # Chemin correct
      - /var/www/html/vendor            # Ignore vendor
      - /var/www/html/storage           # Ignore storage
    # ❌ SUPPRIMER: command: php -S...
    # ✓ LAISSER Apache démarrer automatiquement

    "ext-curl": "*",
