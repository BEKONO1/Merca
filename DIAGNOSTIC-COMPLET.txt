🔴 PROBLÈME IDENTIFIÉ
═════════════════════════════════════════════════════════════════════════════

PHP n'est PAS installé sur votre système Windows
OU
PHP est installé mais PAS ajouté au PATH Windows

PATH = Variable Windows qui dit où chercher les commandes
Sans PHP dans le PATH, Windows ne peut pas trouver "php" ou "composer"
