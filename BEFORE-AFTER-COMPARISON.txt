1️⃣  PORT CONFIGURATION
────────────────────────────────────────────────────────────────────────────

BEFORE (docker-compose.yml):
  ports:
    - "${APP_PORT:-8000}:8000"
  
  command: php -S 0.0.0.0:8000 -t public/

AFTER (docker-compose.yml):
  ports:
    - "${APP_PORT:-80}:80"

IMPACT:
  ✓ Local port = production port (80)
  ✓ Matches Docker Apache that listens on 80
  ✓ Consistent with Dockerfile


════════════════════════════════════════════════════════════════════════════

2️⃣  VOLUME MOUNTS
────────────────────────────────────────────────────────────────────────────

BEFORE (docker-compose.yml):
  volumes:
    - .:/app                 ← WRONG PATH
    - /app/vendor
    - /app/storage

AFTER (docker-compose.yml):
  volumes:
    - .:/var/www/html        ← CORRECT PATH
    - /var/www/html/vendor
    - /var/www/html/storage
    - /var/www/html/public/uploads

IMPACT:
  ✓ Matches WORKDIR /var/www/html in Dockerfile
  ✓ Volumes actually work
  ✓ Code changes reflected in container


════════════════════════════════════════════════════════════════════════════

3️⃣  SERVER CONFIGURATION
────────────────────────────────────────────────────────────────────────────

BEFORE (docker-compose.yml):
  command: php -S 0.0.0.0:8000 -t public/
  
  Problem:
  • Single-threaded built-in server
  • Ignores Apache in Dockerfile
  • NOT using optimized Docker image

AFTER (docker-compose.yml):
  (no command - let Apache start automatically)
  
  Benefit:
  ✓ Uses Apache from Dockerfile
  ✓ Multi-threaded (better performance)
  ✓ Actual production environment

6️⃣  RAILWAY CONFIGURATION
────────────────────────────────────────────────────────────────────────────

BEFORE:
  ❌ Only railroad.json (uses Dockerfile builder)
  ❌ Not aligned with modern standards
  ❌ Manual builder selection

AFTER:
  ✅ railroad.toml (uses docker-compose builder)
  ✅ Aligned with Laravel 12 standards
  ✅ Unified configuration

NEW railroad.toml:
  [build]
  dockerComposeFile = "docker-compose.yml"
  dockerComposeService = "app"
  
  [deploy]
  numReplicas = 1
  healthcheckPath = "/"
  healthcheckTimeout = 30
  healthcheckInterval = 10

IMPACT:
  ✓ Modern configuration approach
  ✓ Same as Laravel 12 template
  ✓ One source of truth
